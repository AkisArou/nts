# Ideas

Directions worth keeping that nobody has committed to. Nothing here is built, and
none of it is a plan: a design that is decided moves to `docs/` and a decision to
`docs/records/`.

- [dev-tools-idea.md](dev-tools-idea.md): a Chrome DevTools Protocol backend in the runtime, so real DevTools front-ends every target.
- [esm-modules-optimization.md](esm-modules-optimization.md): what is left to gain from ES modules, mostly startup and `module#init` size.
- [fuzzer-research.md](fuzzer-research.md): fuzzing the compiler; Fuzzilli does not generate TypeScript, and the alternatives.
- [gate-enhancements.md](gate-enhancements.md): concurrent gates, and a gate on a second machine.
- [gpu-bpf.md](gpu-bpf.md): an RFC draft for compiling parts of a program for GPUs and Linux eBPF.
- [random-notes.md](random-notes.md): the user's own list (array-chain fusion, an optimization linter, a memory-analysis LSP, an MCP over HIR).
- [react-integration.md](react-integration.md): React as if built into Chromium, beyond running it as a native target.
- [web-worker.md](web-worker.md): using the checker's types to drive a concurrency optimizer while sources stay plain TypeScript.
