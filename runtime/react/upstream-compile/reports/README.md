# Experiment reports

Reports in this directory are reproducible evidence tied to the commit in
`upstream.lock.json`. The closure report is generated by `tools/analyze.mjs` and
checked in so React updates expose dependency and syntax changes in review.

`native-react-assessment.md` is the current decision and implementation order.
It separates reusable conversion work, React-specific contracts, NTS blockers
and measured performance implications.

The generated reports also cover normalization, local and linked profile
specialization, the HostConfig surface, strict diagnostics, the generated-code
escape audit, React Compiler goldens and the exact-source upstream behavioral
oracle. `runtime-native-probe.json` classifies every full-runtime NTS refusal,
records verifier failures and checks the reconciler exports required for a
usable build. `blocker-probes.json` runs the strict minimal reproductions.
Markdown reports interpret backend and representation probes whose raw
artifacts remain under the ignored `generated/` tree. The React Compiler build
report hashes every upstream source present in its bundle source map and the
npm lockfile that pins the external build toolchain.
