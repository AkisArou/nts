# Reserved C publication names

Both the unused public spelling and the descriptor-shaped spelling must stop
with NTS2007 on each native emitter. The ordinary `nts_desc_Foo` export and
private reserved-looking function/global/field execute 43 under NoGC and RC.
The private HIR name remains the source spelling used in diagnostics.
These are fatal compiler diagnostics, so the assertions live here rather than
in the construct-refusals runner. JVM native ABI publication is not involved.
